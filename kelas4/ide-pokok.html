📚 Materi 1: Apa Itu Ide Pokok?

📌 Definisi:
Ide pokok adalah gagasan utama yang menjadi inti pembicaraan dalam sebuah paragraf.

🎯 Analogi mudah:

Bayangkan paragraf itu seperti buah mangga 🥭

  • Ide pokok = daging buahnya (isi utama)
  • Ide pendukung = kulit & biji (pelengkap)
💡 Kalimat kunci: "Ide pokok itu seperti JUDUL tersembunyi di dalam paragraf."

Contoh:

Aku sangat menyayangi kucingku, Si Belang. Setiap pagi aku memberinya makan. Aku juga memandikannya setiap minggu. Si Belang selalu tidur di samping tempat tidurku.

Ide Pokok: Aku sangat menyayangi kucingku, Si Belang.

Ide Pendukung: Memberi makan, memandikan, tidur di samping tempat tidur.

📚 Materi 2: Ciri-Ciri Ide Pokok

👆 Klik setiap kartu untuk melihat penjelasannya!

🎯
Inti Paragraf
Kalau ide pokok dihapus, paragraf jadi tidak jelas.
🌐
Kalimat Umum
Tidak menyebut hal-hal kecil/rinci.
🔗
Dijelaskan Kalimat Lain
Semua kalimat lain menopang ide pokok.
1️⃣
Hanya Satu per Paragraf
Tidak boleh ada dua ide pokok!
🎵 Jingle menghafal:
"Inti, umum, dijelaskan, satu saja — itulah ide pokok, ayo cari sekarang juga!"

📚 Materi 3: Letak Kalimat Utama

JenisLetakContoh Posisi
Deduktif ⬇️Awal paragrafKalimat pertama
Induktif ⬆️Akhir paragrafKalimat terakhir
Campuran ↕️Awal + AkhirKalimat pertama & terakhir

Contoh DEDUKTIF:

Olahraga sangat penting bagi kesehatan. Dengan olahraga, tubuh menjadi kuat. Olahraga juga membuat pikiran segar. Selain itu, olahraga mencegah penyakit.

✅ Ide pokok di AWAL.

Contoh INDUKTIF:

Pagi ini aku membantu ibu menyapu. Siangnya aku membantu ayah mencuci mobil. Sore aku merapikan mainan. Aku senang membantu orang tuaku.

✅ Ide pokok di AKHIR.

Contoh CAMPURAN:

Membaca buku memiliki banyak manfaat. Kita bisa menambah pengetahuan. Kita juga bisa memperkaya kosakata. Bahkan, membaca dapat membuat kita lebih pintar. Jadi, membaca buku sangat bermanfaat.

✅ Ide pokok di AWAL dan AKHIR.

📚 Materi 4: Cara Menemukan Ide Pokok

🕵️ 4 Langkah Rahasia Detektif:

  1. 🔍 Baca Cermat — Baca seluruh paragraf dari awal sampai akhir.
  2. 🎯 Cari Kalimat Utama — Kalimat yang paling umum dan dijelaskan kalimat lain.
  3. ❓ Tanya Diri Sendiri — "Paragraf ini membahas tentang apa?"
  4. ✍️ Tulis dengan Bahasa Sendiri — Ubah kalimat utama jadi lebih singkat.

Contoh Penerapan:

Sampah plastik sangat berbahaya bagi lingkungan. Plastik membutuhkan waktu ratusan tahun untuk terurai. Sampah plastik juga dapat mencemari laut dan membunuh hewan laut. Oleh karena itu, kita harus mengurangi penggunaan plastik.

Langkah 1: Dibaca ✔️

Langkah 2: Kalimat utama = "Sampah plastik sangat berbahaya bagi lingkungan."

Langkah 3: Paragraf membahas → bahaya sampah plastik

Langkah 4: Ide pokok = Sampah plastik berbahaya bagi lingkungan.

📚 Materi 5: Ide Pokok vs Ide Pendukung

Aspek🌟 Ide Pokok🔹 Ide Pendukung
FungsiInti paragrafMenjelaskan inti
SifatUmumRinci/khusus
Jumlah1 per paragrafBisa banyak
LetakKalimat utamaKalimat penjelas
Contoh"Kucingku lucu.""Bulunya putih, matanya bulat."
🌳 Analogi Pohon: Batang = ide pokok, daun & ranting = ide pendukung.
